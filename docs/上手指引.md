# 上手指引：注册 GitHub + 配置 DeepSeek + 部署

本指引分三部分，全程约 20–30 分钟。完成后网站每天自动更新，无需再手动操作。

## 一、注册 GitHub 并创建私有仓库

1. 打开 https://github.com ，点击 **Sign up**，用邮箱注册（免费）。完成邮箱验证。
2. 登录后点击右上角 **+** → **New repository**。
3. Repository name 填 `paper-radar`（或你喜欢的英文名）；选择 **Private**（私有）；不要勾选 “Add a README” 等初始化选项；点 **Create repository**。
4. 记录你的仓库地址，形如 `https://github.com/你的用户名/paper-radar.git`。

### 生成访问令牌（Personal Access Token）

本地推送代码和后续自动更新需要令牌：

1. 打开 https://github.com/settings/tokens ，点 **Generate new token (classic)**。
2. Note 填 `paper-radar`；Expiration 选 90 天或更长。
3. 勾选 **repo** 整组权限；点最下方 **Generate token**。
4. **立即复制保存**以 `ghp_` 开头的令牌（只显示一次）。令牌等同密码，不要发给他人或提交到代码里。

## 二、创建 DeepSeek API Key

1. 打开 https://platform.deepseek.com ，用手机号注册登录。
2. 左侧 **充值** 充少量金额（如 ¥10–20，足够用很久；按量扣费）。
3. 左侧 **API Keys** → **创建 API Key**，复制保存（只显示一次）。

## 三、把代码推上去并开启自动更新

### 方式 A：让 Codex 帮你完成（推荐）

在 Codex 对话中告诉它：

> 我已注册 GitHub（用户名：XXX），仓库地址：https://github.com/XXX/paper-radar.git，令牌：ghp_XXX；DeepSeek API Key：sk-XXX。请把项目推送到仓库并完成 Secret、Pages 与首次运行配置。

Codex 会完成推送、添加 Secrets、启用 Pages、触发首次运行，并告诉你最终网址。

### 方式 B：手动操作

1. 在项目目录打开终端，初始化并推送（把令牌与地址换成你自己的）：
   ```bash
   git init
   git add .
   git commit -m "init: 文献雷达 v1.1"
   git remote add origin https://ghp_XXX@github.com/XXX/paper-radar.git
   git push -u origin main
   ```
2. 打开仓库页面 → **Settings → Secrets and variables → Actions → New repository secret**，添加：
   - `DEEPSEEK_API_KEY` = 你在 DeepSeek 平台创建的 Key
   - （可选）`OPENALEX_MAILTO` = 你的邮箱
3. **Settings → Pages**：Source 选择 **GitHub Actions**，保存。
4. 打开 **Actions** 标签页 → 左侧 **每日更新文献雷达** → 右上 **Run workflow**，手动触发一次。
5. 等 2–5 分钟运行完成，回到 **Settings → Pages**，页面顶部会显示你的网址 `https://你的用户名.github.io/paper-radar/`。
6. 之后每天北京时间 06:00 自动更新；也可随时在 Actions 里手动触发。

## 验证是否成功

- 打开网页能看到当周相关文章与中文总结；
- 第二天打开，能看到前一天的新文章；
- 若某篇没有总结，说明当次 DeepSeek 调用失败，下一天会自动重试。
